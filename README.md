# GTU Discovery Service

Este proyecto es el servicio de descubrimiento para la arquitectura de microservicios de GTU. Utiliza Eureka para registrar y descubrir los microservicios.

## Descripción

El servicio de descubrimiento es una parte esencial de la arquitectura de microservicios, ya que permite que los diferentes servicios se encuentren y se comuniquen entre sí. Este proyecto implementa un servidor Eureka que actúa como un registro donde los microservicios pueden registrarse y descubrir otros servicios.
